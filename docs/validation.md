## 研究流程调研样例

公开样本 [Me at the zoo](https://www.youtube.com/watch?v=jNQXAC9IVRw) 长 19 秒，实际为 320×240、15 fps。匿名媒体获取得到 629,172 字节，耗时 3.66 秒，英文人工字幕下载得到 6 条 cue。通过调研脚本手工连接既有 BVR `inspect_video_window`，对 0 至 15 秒去音轨后进行了一次 StepFun 分析，工具耗时 23.41 秒。

模型识别出大象，第 8 秒附近的源帧支持类别判断。但“两个动物下半身全程被遮挡”的描述与源帧可见腿部的情况不符；回答还生成了无采样依据的帧号和精确时刻。因此本例证明媒体、字幕、FFmpeg、MCP 和 Provider 能连接，同时暴露了逐条证据和时间精度问题。它不是 Catalyst 正式 Adapter 的验收，也不是模型准确率基准。

本例的 Provider usage 与费用未返回，保持未知。

## Catalyst 编译版真实调用

2026 年 11 月 2 日，通过编译后的 stdio MCP 服务调用统一工具 `analyze_video_url`。环境为 Node.js 26.12.0、yt-dlp 2026.10.26、EJS 0.8.0、外部 FFmpeg 9.0.1；分析模型使用 StepFun `step-3.7-flash`，B 站 ASR 使用 `stepaudio-2.5-asr`。

| 来源与模式 | 源区间 | 返回状态与耗时 | 证据与处理 |
| --- | --- | --- | --- |
| [YouTube Me at the zoo](https://www.youtube.com/watch?v=jNQXAC9IVRw)，`language` | 0 至 15 秒 | `complete`，15.61 秒 | 元数据和 5 条字幕 cue，共 6 条 Evidence、1 条 Finding；未下载媒体。 |
| 同一 YouTube 视频，`vision` | 3 至 12 秒 | `complete`，31.35 秒 | 320×240、15 fps；下载 533,931 字节媒体，返回 2 条 Evidence、4 条 Findings。 |
| [BVR 演示视频](https://www.bilibili.com/video/BV1dPeP6REwM/)，`language` | 0 至 15 秒 | `partial`，25.57 秒 | 元数据和 ASR 共 2 条 Evidence、1 条保留 Finding；获取 1,782,375 字节纯音频后按窗口转写。 |

B 站字幕状态为 `auth_required`：字幕 API 没有复用下载器已有的授权浏览器登录态，而下载器可以取得音频。因此流程记录字幕访问限制，并明确使用 ASR 回退。模型另返回的一条无效引用被丢弃，结果保留有效证据与一条有效引用的 Finding，以 `partial` 表达真实降级。

三次调用中保留的 Findings 均为 `verification: "unverified"`，引用 ID 均指向实际存在的 Evidence。这里只核查了集成、状态与引用结构，没有把这些结果作为模型准确率或精确时间定位基准。三次结果的 Provider usage 均为 `null`，费用未知。

## 小红书接入与真实调用

2026 年 11 月 2 日接入实验性 `XiaohongshuAdapter`。支持原始笔记链接、官方 `.com`/`.cn` 短链和包含单条 URL 的完整分享文案；输入 HTTP 短链在访问前升级为 HTTPS。获取保留分享参数，对外结果隐藏这些参数和临时签名媒体地址。平台字幕与评论尚未接入，语言模式明确使用 ASR。

旧提取器测试链接均未取得视频；新增公开样本中，以下两条在未配置任何平台 Cookie 的环境里成功取得元数据：

| 公开来源 | 适配器结果 |
| --- | --- |
| [西安交大官方报道](https://news.xjtu.edu.cn/info/1219/235513.htm)中的[获奖短片](https://xhslink.cn/o/8KUUva15p82) | 笔记 `6ad39a38000000001301bbd9`，标题《学校重阳节视频。》，52.2 秒，1280×720、29 fps、h264/aac。 |
| [开发者本人帖子](https://origin.v2ex.com/t/1249491)中的[腕拍演示](https://xhslink.cn/o/AP6KZd9X5g0) | 笔记 `6ad1b3fd0000000014003714`，标题《手表遥控大疆相机，国区已上架》，29.767 秒，720×1280、30 fps、h264/aac。仅验证元数据。 |

同一轮里，用 Python 跟随全部跳转或让 yt-dlp 直接处理上述短链会到登录页；本实现先用 Node 逐步解析短链，遇到正式笔记 URL 即保留完整参数并交给专用提取器，成功取得视频元数据。具体客户端差异尚未隔离，不能据前一种失败推断来源不可用，也不将此写成平台长期规则。另有新旧样本返回登录页或错误 `300031`；HTTP 200 和存在页面初始状态都不代表拿到了视频。

对交大短片，通过编译后的 stdio `analyze_video_url` 传入包含 HTTP 短链的完整分享文案，实际下载、裁剪并研究源视频 0 至 12 秒。使用既有授权的 StepFun `step-3.7-flash`/`stepaudio-2.5-asr` 配置，Node.js 26.12.0、Python 3.14.7、yt-dlp 2026.10.26 与 FFmpeg 9.0.1；未配置平台 Cookie。

| 模式 | 结果与总耗时 | 证据及结论 |
| --- | --- | --- |
| `language` | `complete`，17.02 秒 | 元数据与 ASR 共 2 条 Evidence、1 条 Finding；ASR 得到离家求学相关旁白。 |
| `vision` | `complete`，27.52 秒 | 元数据与静音视频窗口共 2 条 Evidence、6 条 Findings。 |
| `multimodal` | `partial`，27.49 秒 | 元数据与原视频窗口共 2 条 Evidence、3 条保留 Findings；另 1 条无效引用被丢弃。 |

每次下载完整的 14,419,115 字节源文件，然后裁剪；三次请求没有跨请求缓存。三份结果的引用均指向现有 Evidence，源时间范围为 0 至 12 秒，分享参数没有出现在返回结果中，Provider usage 均为 `null`。抽查源视频第 2、6、10 秒画面，可见桌面绘图场景、播放图标过渡和卡通头像，支持主要场景判断；未逐条核验全部结论。所有保留结论仍为 `verification: "unverified"`。视觉回答仍出现无确定采样依据的帧号和小数秒，多模态回答对音频的描述也不充分；这些是模型表现限制，`complete` 不代表语义准确或精确定位验收通过。

本轮 **66 项离线测试全部通过，无跳过项**，另通过类型检查、构建和 `git diff --check`。新增测试使用伪下载器、模拟 Provider 和真实 FFmpeg 生成的短片，覆盖完整分享文案的三模式调用、1 至 3 秒非零窗口、ASR 单声道 16kHz 音频、视觉无音轨、多模态保留音轨、参数脱敏、清理、凭据隔离以及无格式/图文/受限访问的区别。上述测试与真实平台验证分别记录，不能相互替代。

## 小红书图文独立路径

用户日用样本[《这样的 Agent 自动化系统，用着不烧心》](https://xhslink.cn/o/Af8twEpdOVh)实际为“数字生命卡兹克”发布的 32 页图文长文，笔记 ID 为 `6ae80a83000000001a0153d3`。桌面请求曾跳到登录页；保留分享参数的移动端页面可匿名返回 `__SETUP_SERVER_STATE__.LAUNCHER_SSR_STORE_PAGE_DATA.noteData`，其中实际类型为 `normal`，带 `long_text_to_image`，有 32 张图片且没有视频。此前单纯使用视频提取器得到的空格式错误不能正确说明这一情况。

新增 `analyze_xiaohongshu_note` 后，图文通过独立正文/图片路径研究，确认是视频时复用原视频流程。通过编译后的 stdio MCP，用原始分享文案、已有 StepFun 配置及本地 Apple Vision OCR 完成以下真实调用，未配置平台 Cookie：

| 模式与范围 | 状态、总耗时 | 程序记录的证据覆盖 |
| --- | --- | --- |
| `text`，整篇 | `complete`，77.17 秒 | 下载 7,467,682 字节，原始 1–32 页全部 OCR；正文 1 条、图片文字 32 条，共 33 条 Evidence、8 条 Findings。 |
| `vision`，第 24 页 | `complete`，56.08 秒 | 下载 218,815 字节，仅一张原图；1 条画面观察、2 条 Findings，程序将批内图片序号映射回原始页码。 |
| `combined`，第 24 页 | `complete`，56.63 秒 | 同一张图的文字与画面观察分别保留，2 条 Evidence、3 条 Findings；同一服务进程复用了前次 OCR。 |

三份结构化结果的引用均指向实际存在的证据，输出不包含分享参数、CDN 地址或临时文件路径，usage 保持未知。图文结果没有伪造视频时长或时间戳，选页结果没有混入整篇正文。一次源获取单独验证按 `[32,1]` 请求后仍保留原始顺序 `[1,32]`，销毁后临时目录不存在。

复测前的第 24 页视觉调用曾因模型返回错误页号而被标记 `partial`；代码未接受该错误引用。提示与页号映射已修正，并通过原图非第一页的回归验证。模型回答仍有实际局限：曾把已处理的 32 张图片误说成 31 张，流程图节点“完整检查”和部分箭头方向也出现 OCR 或视觉误读。覆盖范围以程序的 `selected_pages`/`processed_pages` 为准，不能把 `complete` 或有效引用结构当作语义准确率验收。

本轮 101 项离线测试全部通过，无跳过项；类型检查、构建及 diff 检查通过。测试覆盖 JSON 安全解析（不执行页面脚本）、两种页面状态、身份/类型核查、图片顺序与选页、流式字节限制、取消与清理、跨平台 OCR 路由、图片内联请求、缓存隔离和页号映射。无文字照片可用 `combined` 取得视觉证据，空 OCR 保留告警；文字模式缺页或看不清时保留部分结果。原有视频测试继续作为回归检查。

## 验收案例

下面六类案例覆盖完整的首版验收设计。上述真实调用覆盖其中的部分路径，其余受控夹具和语义核验仍需分别执行。

| 案例 | 输入与参考 | 核查内容 |
| --- | --- | --- |
| 有字幕的语言事实 | 有人工字幕的短片；人工记录两个关键事实与源 cue | 字幕存在时不下载媒体或调用 ASR，结论引用真实 cue，来源语言正确。 |
| 无字幕 ASR 回退 | 无平台字幕且讲话清晰的短片；人工转写 | 仅提交音频，区分字幕缺失与失败，不生成不存在的词级时间。 |
| 视觉独有信息 | 静音片段中的已知标签或动作，元数据和字幕没有答案 | 音轨确实移除，模型识别正确，语言路径不猜测画面。 |
| 非零窗口时间映射 | 已知第 27 秒发生事件，请求 25 至 35 秒 | 源窗口保留，偏移只应用一次，精度与依据明确。 |
| 失败与部分结果 | 参数错误、网络阻断、认证要求、质量不足与 Provider 失败 | 阶段、代码和状态可操作，保留已取得证据，不把失败写成内容事实。 |
| 重复研究与成本 | 同源不同问题，再改变画质或窗口 | 记录下载/转写/模型调用数、耗时与字节；当前无缓存时按真实基线报告。 |

结构化检查可以确定证据 ID 是否存在、时间范围是否有效；不能自动确定模型结论在语义上受证据支持。比较准确率或定位误差前，应先固定参考答案与容差。

## 本地检查

```bash
npm run typecheck
npm test
npm run build
npm run doctor
```

离线测试不得请求真实视频平台或模型。doctor 仅执行本机版本/import 探针和配置存在性检查。未配置 Provider 的干净环境会返回缺少凭据，EJS 无法确认时返回告警；这两种状态都应如实记录。

真实烟测应从公开短片、明确源区间和有限请求数开始。原始日志不应包含凭据、Cookie 内容或临时签名媒体地址。Provider usage 未返回时，记录未知值，不能从耗时推算收费。

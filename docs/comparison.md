# 多来源证据对照

`compare_research_materials` 对宿主明确选定的 2–3 份已读材料研究同一个问题，保留每份材料的来源、读取限制及引用位置。材料可以来自视频研究、小红书图文研究，或本地长视频记录。工具准备已有证据后，最多调用一次文本 Provider 生成对照。

## 使用方式

把已有工具返回的完整结构化结果交给对照入口：

```text
compare_research_materials({
  question: "这些材料对高效注意力的适用条件有哪些共同说法和分歧？",
  materials: [
    { kind: "video", result: <analyze_video_url 的完整结果>, label: "视频讲解" },
    { kind: "xiaohongshu", result: <analyze_xiaohongshu_note 的完整结果>, label: "图文笔记" }
  ],
  language: "zh",
  max_comparisons: 6,
  timeout_seconds: 120
})
```

`result` 占位符需要替换为已有工具的完整结果对象，不能只传搜索候选、链接、最终答案或自行拼写的证据 ID。小红书工具的外层结果使用 `kind: "xiaohongshu"`；已取出的图文内部结果使用 `kind: "note"`。

已保存的长视频结果可以通过只读引用提供：

```text
materials: [
  { kind: "session", session_id: "<第一份 session.id>", label: "课程讲解" },
  { kind: "session", session_id: "<第二份 session.id>", label: "另一份讲解" }
]
```

| 参数 | 规则 |
| --- | --- |
| `question` | 3–2,000 字符的本轮对照问题。源结果的最终答案不会作为本轮答案直接复用。 |
| `materials` | 明确选定的 2–3 项。支持 `video`、`note`、`xiaohongshu` 完整结果，以及 `session` 本地记录引用。 |
| `label` | 每项可选的展示名称；不承担来源身份或证据作用。 |
| `language` | 可选的本次输出语言，不改写原证据的来源与定位。 |
| `max_comparisons` | 对照条目上限，默认 `6`，范围 `1–8`。 |
| `timeout_seconds` | 准备材料和模型调用共用期限，默认 `120` 秒，范围 `1–300` 秒。 |

输入总量受 2 MiB 上限约束，准备后的模型提示受 200,000 字符上限约束。每份材料最多 80 条原 Evidence、最多 80 条准备后的比较证据，整次最多 200 条；单条可引用文本最多 32,000 字符。超限明确报告，不静默截取部分材料后声称已对照全部内容。

## 证据的两种依据

对照保留独立的 `ComparisonEvidence`，每项都有本轮唯一 ID、`material_id`、源结果中的 `original_id`、可引用文本及 `locator`。视频引用保留实际源时间范围；图文引用保留原图片页码；正文可使用空页码。不同结果里的同名证据 ID 经过材料命名空间隔离。

| `basis` | 可提供的依据 | 本轮使用边界 |
| --- | --- | --- |
| `source_text` | 已有字幕、ASR、笔记正文或 OCR 文本。 | 可针对新问题重新分析；原始读取、转写、OCR 和时间精度限制继续保留。 |
| `derived_observation` | 通过原结果引用校验的视觉 Finding 陈述。 | 仅在原问题与本轮问题相同、且原引用指向同一定位时使用。它是已有模型观察，没有重新查看原画面；换问题需要先补读相关画面。 |

源结果的最终 `analysis` 不进入对照提示。标题、作者及来源标签只用于识别材料，搜索摘要、元数据和评论也不能替代本入口的主要内容证据。程序会检查证据来源、原 ID 及定位关系，保留可用材料并明确标出不能使用的部分。

首版对视觉观察采用原问题与新问题去除首尾空白后文本一致的检查，不自动判断翻译或改写后的问题是否等价。

`source_text` 的“原始”指已有获取结果中的内容，并不表示 ASR／OCR 已被人工核验。`derived_observation` 的文本是有效原 Finding 的陈述，不是视频台词或图片逐字原文。

## 逐条对照与引用

每条对照包含一个待比较的 `claim`，以及各材料的 `positions`：

| 立场 | 含义 |
| --- | --- |
| `supports` | 所给证据支持这份材料对该命题的表述。 |
| `contradicts` | 所给证据明确给出与该命题相反的表述。 |
| `not_addressed` | 这份已提供材料没有涉及该命题；不能据此认定原始完整视频或整篇笔记均未讨论。 |
| `insufficient` | 当前证据不足、范围不全、读取失败或含义无法确定。 |

程序先把每项证据内容分成连续的短摘录，每条最多 180 字符，并绑定原证据 ID、所属材料和时间／页码。模型被要求为支持和反驳立场选择摘录编号，程序再回填原摘录及其来源，不让模型重新拼写或跨页拼接引文。较长上下文可以引用相邻的多条摘录，每项最多 6 条。

返回给宿主的引用仍为 `citations` 中的 `evidence_id` 与 `quote`。程序继续检查摘录是否属于该材料、是否来自有效证据，以及 `quote` 是否是该证据 `content` 中实际存在的精确子串；错误编号、跨材料引用或拼接／改写后的引文不会因此获得宽松路径。切分摘录不会把省略内容冒充完整读取；提示仍受总预算约束，超限明确报错。

引用到派生观察时，子串匹配的是该观察陈述，不能冒充原媒体的逐字核验。原 Finding 联合引用多个不同窗口或图片页时，整条派生观察会被排除，并将材料保留为部分结果；不能把联合结论复制到各局部定位，伪装成单窗口或单页支持。同一定位的多通道证据可以保留一条派生观察，并列出完整原引用。没有谈到某个主题或没有读取相应范围，不会自动成为反对立场。

程序在引用通过后重新计算 `relation`，而不照收模型给出的关系：

- `shared`：至少两组来源的有效立场共同支持或共同反驳同一命题。
- `disputed`：有效立场同时包含支持和反驳。
- `single_source`：目前只有一组来源提供可用立场。
- `insufficient`：缺少可用于比较的有效立场。

关系表示这些材料里的陈述情况，不裁定命题为真或为假。最终可读 `analysis` 从通过校验的对照行生成；无效行不会混进答案。每行继续保留 `verification: "unverified"`，引用存在和位置有效只说明结构成立，不能证明语义支持关系正确。

## 来源关系与重复材料

`source_key` 标识来源内容，视频保留分 P；`source_group` 将同平台同视频 ID 的不同分 P 归入一组，同一笔记 ID 也只属于一组。同组的后续材料通过 `duplicate_of` 指向更早输入，显式标出来源关系，各自范围和证据仍保留。重复输入不能增加独立佐证数量；同一视频的两个分 P 可以包含不同内容，但不被描述成两个独立来源。

结果固定声明 `source_independence: "not_established"`。跨账号、跨平台转载或共同引用同一篇论文的关系没有自动核验；措辞相似不能直接证明抄袭，措辞不同也不能证明独立。对照中的共同说法不能通过简单数票升级为事实已证实。

## 状态、成本与保存

各项材料分别记录 `ready`、`partial` 或 `unavailable`，并返回可用证据、限制与错误。某项材料不可用时，其他可用材料继续保留；结果的完整性与实际有效材料、输出和错误相符。没有可用的比较证据或模型输出时，会保留已准备的信息和具体失败原因。

工具读取已有结果和指定本地记录，最多做一次文本模型调用，不访问平台、不下载媒体、不做 ASR 或 OCR、不重新分析视频或图片，也不自动续跑材料。调用模型仍可能产生 Provider 费用；Provider 没有返回的使用量或费用不能被推算成已知值。

本轮对照返回内存结果，不创建通用研究项目或新的持久会话。引用 `session_id` 只读取现有记录，不改写、不续跑或删除它。需要新的原始材料、更多来源或更细画面时，由宿主发起对应研究工具调用，再重新对照。

材料反映已有结果保留的内容和读取范围；本次没有重新确认平台页面或媒体的当前状态。

| [FEVER 数据集与任务定义](https://fever.ai/2018/task.html) | 支持、反驳与信息不足是不同标签；判断依赖给定证据。 | 立场区分明确反对、未涉及与证据不足，不把沉默或未读范围当作反驳。这里对照材料说法，不声称完成事实裁决。 |
| [ALCE，EMNLP 2023](https://aclanthology.org/2023.emnlp-main.398/) | 将回答正确性与引用质量分别评估，关注引用的支持性与覆盖。 | 精确子串和有效引用只做结构检查；人工／语义验收另记。模型解释持续标为未核验，不能因引用可解析就提升为正确。 |

## 验收要求

实际调用与测试计数单独记入[验证记录](./validation.md)。

| 场景 | 必须观察到的结果 |
| --- | --- |
| 视频和图文包含同样或相反说法 | 按有效立场给出对照，引用仍指向各自时间范围或图片页码。 |
| 一份材料未涉及、一份材料读取失败 | 与明确反对分开，保留未读和不足限制。 |
| 多份结果使用相同原证据 ID | 本轮命名空间不同，不能串源引用。 |
| 模型选择错误摘录编号、跨材料引用或拼接引文 | 对照行被拒绝，不进入生成后的可读答案；有效编号回填后仍与原证据子串逐字一致。 |
| 重复输入同源结果或同视频不同分 P | 不增加独立佐证数量；依赖关系始终不宣称已建立。 |
| 改问新问题 | 原始语言／OCR 文本可重新分析；旧最终答案不进入提示，旧视觉 Finding 不直接复用。 |
| 超限、取消或 Provider 失败 | 有界结束并保留已准备的来源及明确状态，不隐式重新获取媒体。 |
| 读取保存会话参与比较 | 会话内容和版本保持原样，没有平台或媒体请求。 |

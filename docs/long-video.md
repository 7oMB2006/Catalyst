# 长视频研究：设计与验收

`analyze_long_video_url` 对单条视频或选定分 P 进行分段概览，再精读与问题相关的片段。普通 `analyze_video_url` 继续限制单次媒体区间为 900 秒；宿主可以根据视频长度选择长视频入口。长视频默认保存本地读取记录，可通过 `resume_long_video_research` 恢复同一问题的未完成读取。harness 管理后续问题、来源选择和综合回答；候选搜索使用独立的 `discover_bilibili_videos`。

## 用户场景

验收来源是用户指定的 [B 站课程第 17 P](https://www.bilibili.com/video/BV1DTxXzUEvW/?p=17)。2026 年 11 月 3 日查询到的分集信息为：

- 合集包含 52 P；本次只研究第 17 P。
- 分集名为「17、各式各样神奇的自注意力机制 Selfattention」。
- CID 为 `38253823575`，本集时长 4,276 秒，即 1:11:16。
- 匿名字幕接口返回 `auth_required`；这不等于视频没有字幕。媒体获取可以使用显式配置的授权会话。

验收问题是「这一节课介绍了哪些自注意力机制，各自解决什么问题？」。课程名称不能代替内容证据；声音解释和 PPT、公式的视觉观察分别描述，看不清的细节保留不确定性。

## 处理计划

1. 解析来源、分 P、CID、时长和素材状态。B 站结果保留合集标题及 `metadata.part_title`。
2. 在获取媒体前，把所选原视频范围完整划分为不重叠的概览窗口。默认每段 600 秒，最多 12 段；预算不足时返回 `PLAN_BUDGET_EXCEEDED`，不只读开头后声称完整。
3. 逐段获取并解释素材。`language` 优先使用可用字幕，否则转写所选区间音频；`vision` 去除音轨；`multimodal` 保留音画并显式转写同一窗口的音频，以独立 ASR 引用提供语言证据，避免仅靠视频接口是否暴露音频来推断讲解。
4. 从有有效结果的概览段中按相关性选取最多两个精读窗口，默认每个 120 秒。模型建议的局部焦点先校验范围，再转换为原视频时间并重新获取实际片段。该建议只是导航，不能当作已核验的事件时间。
5. 规划完成、每段结束、精读计划确定及任务结束时保存检查点。精读窗口先完整规划再执行，续跑保留已确定的窗口和引用身份。
6. 用实际来源引用、分段报告和覆盖情况综合回答。超时、取消或部分失败保留已完成报告，未完成部分继续显示；续跑后重新综合。

第 17 P 的默认概览计划为 `0–600`、`600–1200`、`1200–1800`、`1800–2400`、`2400–3000`、`3000–3600`、`3600–4200`、`4200–4276` 秒。全部时间都相对于本集开头，不相对于合集或截取后文件。

## 媒体获取与预算

- `yt-dlp --download-sections` 获取所选区间，配合 `--force-keyframes-at-cuts`；不静默回退到全源下载。要求分段起止标记匹配，并校验实际文件时长，以拒绝忽略裁剪或截断的产物。这些检查仍不构成首帧内容对齐的独立证明。
- 远程 FFmpeg 输入启用 TLS 证书校验，并使用当前 Node 默认 TLS 客户端的有效 CA 集合写入临时信任文件。额外或系统 CA 只在 Node 已配置采用时继承；不关闭校验来处理证书错误。信任文件与媒体目录一起回收。
- 默认概览优先获取不超过 480p 的源，精读优先不超过 720p；无低分辨率源时选实际最低分辨率并报告回退，再按准备阶段的上限缩小。显式 `source_quality` 继续控制源质量要求。
- 概览上传前限制到最高 360p、1 fps；精读到最高 720p、5 fps；不放大小源。多模态保留音轨，视觉模式移除音轨。
- 单份准备后的媒体最多 32 MiB。FFmpeg 达到大小限制时可能成功退出，因此还要校验输出时长，不能把截断文件当作整段。
- 单次获取受 `CATALYST_MAX_MEDIA_MB` 控制，默认 256 MiB，并接受请求中剩余的累计文件预算；累计预算默认 512 MiB。轮询临时目录限制文件增长。**这些是文件预算，不是网络流量的硬上限**：远端实现、探测与重试可能产生额外流量。
- 默认共享期限为 900 秒，可设置 5–1,800 秒，覆盖获取、模型和综合回答。单个窗口另有默认 180 秒期限，可通过 `window_timeout_seconds` 设置为 15–600 秒；一个窗口停滞不会直接耗尽整个任务期限。FFmpeg 网络读取等待限制为 15 秒。宿主工具超时需额外覆盖启动开销。不会在返回后自动后台续跑。
- 每段结束后释放临时文件，后续精读可能重新获取同一区间。已保存记录的已完成段可直接复用报告和证据，不重新下载或转写；失败或不完整段会重新处理。媒体文件不持久保存，独立研究之间没有共享缓存。
- 暂时性获取失败最多重试一次，重新提取来源信息，仍共享原窗口期限和剩余文件预算。匹配区间标记后的短缺产物归类为 `MEDIA_INCOMPLETE`，拒绝分析并允许重新获取；缺轨只在本次所选格式确实宣称含该轨时允许重试。认证、错误区间、超长产物和画质错误不重试。平台整数时长与流时长相差不超过 1 秒时，只对终段允许已验证的终点 clamp，实际获取片长保留在证据中。

## 结果与覆盖

结果沿用 Evidence、Finding 和独立能力状态，并增加：

| 字段 | 含义 |
| --- | --- |
| `plan` | 请求范围、全部概览窗口、精读与文件预算 |
| `segments` | 每段的阶段、原时间范围、素材类型、状态、报告及引用 |
| `coverage.overview` | 成功形成有效结构化报告的概览窗口 |
| `coverage.detail` | 成功精读的窗口，独立于概览 |
| `coverage.unreviewed` | 所选范围中没有成功报告覆盖的区间 |
| `coverage.overview_complete` | 全部所选范围是否有成功概览覆盖 |
| `session` | 保存记录的 ID、版本、创建／更新时间，以及本次复用与处理段数；未保存时为空 |
| `follow_up` | 追问的父记录 ID、父版本和复制的原始语言证据 ID；普通初始研究不含此字段 |

概览窗口完整覆盖不等于逐帧阅读，也不证明每张幻灯片、每个公式均被识别。字幕窗口仅代表语言材料，不代表画面覆盖；字幕间可能存在空隙。已经上传媒体但没有成功解释的段落不会算作成功覆盖，也不能成为最终 Findings 的引用来源。

`complete` 要求概览完整、所执行阶段成功且综合结果含有效引用。`partial` 保留有效分段结果及失败信息；没有可用主要素材时为 `unavailable`。结构化引用不能证明语义正确，所有 Findings 仍标记为 `unverified`。

续跑不允许修改问题、模式、来源与分 P、语言、画质或分段计划。允许为本次调用调整期限和累计文件预算；保存的报告不占本次下载预算。记录管理、存储上限、访问链接及恢复边界见[研究记录与断点续跑](./research-sessions.md)。

新问题由 harness 使用已返回的原始字幕／ASR 和来源定位回答；需要时通过 `get_research_session` 取回保存材料。新问题需要检查画面时，由 harness 选择明确时间窗，调用 `analyze_video_url` 的 `vision` 模式读取新证据。旧视觉解释不能自动作为新问题已检查画面的证明。[连续追问工具](./long-video-followup.md)仅在 `node dist/legacy-research.js` 兼容入口提供。

## 验收要求

- 第 17 P 的 URL、CID、时长和分集名贯穿解析、获取、证据与综合结果，旧 BVR 入口也不能错用第 1 P 元数据。
- 用非零起点区间验证获取和引用映射；用 4,276 秒全片验证尾段、概览覆盖与精读范围。
- 断开单段获取或模型调用后，完成区间仍存在，失败区间仍列出，不能返回假完整结果。
- 验证预算不足的前置拒绝、取消和超时、临时文件回收、非法引用丢弃、视觉去音轨、语言与视觉材料边界。
- 中断并重启服务后，复用已完成概览和精读，只补失败或未完成段；重新综合的引用唯一且可解析，概览和精读覆盖独立更新。详细恢复验收要求见[研究记录与断点续跑](./research-sessions.md#验收要求)。
- 离线测试使用替代下载器、注入依赖和真实微型 FFmpeg 素材；真实调用单独记录状态、用时、覆盖及限制。不得把离线通过写成真实平台或模型准确率保证。

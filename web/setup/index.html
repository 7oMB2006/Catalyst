模型和工具

选择用于读取来源的模型。已有 API Key 不会在页面上显示。

一个多模态模型负责文字、图片、视频和音频转写。

一个多模态模型负责阅读，另一个模型负责音频转写。

外部工具路径

使用内置或默认工具时可以留空。自定义路径会影响视频获取和处理。
